2D Discrete Wavelet Transform (2D-DWT) Decomposition

Decomposes carrier video frame into 4 frequency subbands ($LL, LH, HL, HH$) using 2D Haar Wavelets for imperceptible data hiding.

4-Quadrant 2D Haar Wavelet Decomposition Active Frame Subbands
LL Approximation Sub-Band (Low-Low)

Contains fundamental average illumination and coarse structure of the frame. Kept clean to prevent visual distortion.

HL Vertical Detail Sub-Band (High-Low)

Captures vertical edges and sharp boundaries. Ideal for steganographic embedding masked by Human Visual System (HVS).

LH Horizontal Detail Sub-Band (Low-High)

Captures horizontal texture variations and fine lines. Used as carrier sub-band for secret bits.

HH Diagonal Detail Sub-Band (High-High)

Contains high-frequency diagonal noise and texture corners where bit modifications produce zero noticeable visual artifacts.

Architectural Comparison: Spatial LSB vs Transform 2D-DWT

Evaluation Parameter Spatial Domain (LSB) Transform Domain (2D-DWT) Key Advantage
Embedding Domain Spatial (Pixel Intensity Planes) Frequency / Wavelet Domain DWT operates on multi-resolution frequency subbands
Decomposition Method Direct Bit-Plane Slicing (Bit 0 to Bit 7) 2D Haar Wavelet Decomposition ($LL, LH, HL, HH$) DWT separates structural approximation from details
Hiding Location Least Significant Bit of RGB channels High-Frequency Detail Subbands ($HH, HL$) DWT masks modifications in high-contrast edge regions
Visual Fidelity (PSNR) High (~70 – 74 dB) Superior (> 75 dB) Both provide near-zero perceptible distortion
Robustness Sensitive to lossy compression High resistance to compression DWT survives image filtering and compression
Payload Capacity High (up to 3 bits/pixel) Moderate (0.75 – 1.5 bits/pixel) LSB provides maximum raw throughput
Integrity Validation 32-Bit CRC32 Packet Checksum 32-Bit CRC32 Packet Checksum 100% verified lossless recovery
